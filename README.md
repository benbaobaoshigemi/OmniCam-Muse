# OmniCam Muse

OPPO Find X9 Ultra（PMA110）的相机增强模块：KernelSU 模块加 LSPosed 设置应用。原生库和钩子在相机进程里工作，模块文件通过 KSU 绑定挂载覆盖 `/odm` 配置。当前版本 **Muse 4.0.0**，相机 7.006.119。

OmniCam 分 Aura、Muse、Opus 三个阶段。Muse 包含 Aura 的全部功能，并进一步改到原厂 HAL、相机框架和成像链路，处理画质、色彩和交互逻辑。

## 功能

### 拍照画质

- **拍照模式自然化**，下面三项分别开关：
  - 关闭 AI 细节增强：文字和纹理不再被网络重绘，同时关闭头发锐化。
  - 关闭局部对比度增强（LCE）。
  - 进一步柔化：对大师模式和理光模式不生效。
- **放宽 25MP 自动切换条件**：放宽照度、ISO、温度和运动方面的限制，配合相机设置里的"超清优先"使用。

### 大师色彩

- 八个色彩家族：
  - **OPPO**：原厂大师色彩，可选 Find X9 Ultra 或 Find X7 Ultra。
  - **基础**：场景色彩经 Adobe Standard 标定后只套一条传输曲线，有标准、直通、Rec.709、Gamma 四种。
  - **HNCS**：哈苏自然色彩，色彩映射和色调曲线可以分别选"标准"或"复制"。
  - **Lumix**：松下 S9 的 15 种照片风格，包括 L.ClassicNeo、709 Like、Cinelike D2 / V2、Flat 和多种单色。
  - **胶片（Spektrafilm）**：20 种胶片。负片可以搭配 8 种相纸或电影拷贝（Kodak 2383 / 2393、Endura 系列、Fujifilm Crystal Archive），反转片直接扫描；CMY 密度可以分别调。
  - **Canon**：EOS R5 的标准、人像、风光、中性、可靠设置、单色。
  - **Darktable**：Sigmoid、Filmic、AgX 三种色调映射，可以调黑白点、趾部和肩部、对比度、色相保持。
  - **Leica M9**：徕卡 M9 的矩阵和色调渲染。
- **混合模式**：影调和色彩分别按权重混进原厂大师色彩。**替换模式**：完全替换原厂大师色彩。
- **曝光对齐**：把所选色彩对到原厂大师模式的曝光，可选中灰、中间调、高光、白点。

### 大师模式效果栏补充

- **大师颗粒**：强度和大小两把尺子分别调，交互和专业模式的色温、色调一样。所有滤镜都能用，包括没有 LUT 的"标准"；数值按滤镜分别保存。
- **对比度**：-100～100，用理光 GR 的对比度曲线，作用在原厂影调之前。

### 大师滤镜

- 扩展滤镜，包括旧版经典、徕卡、富士、理光、胶片模拟。
- 长按拖动排序，可以隐藏或显示；隐藏的滤镜，绑定它们的预设照常能用。
- **拍照模式同步大师滤镜列表**：拍照、人像和哈苏超清用同样的顺序和显示状态，并加入扩展滤镜。
- **霓虹**：套用普通模式 800T 的光晕和颗粒。**和光**：套用 Portra 的高光溢光。
- **导入与备份**：可多选导入 Rec.709 的 `.cube` LUT，备份和恢复配置。

### 柔光与胶片模拟

- **物理柔光**：三挡柔光可以分别换成光学模拟，散射按场景光计算：弱挡 HDF，中挡 1/4 黑柔，强挡白柔。
- **和光物理胶片**：按柯达实测锐度模拟 Portra 400 的散射、光晕和边缘效应，只作用于成片。

### 哈苏超清

- **滤镜与调色盘**：用拍照模式的滤镜、调色盘和柔光，入口在取景框角落。
- **200MP 解除人脸识别门禁**：画面里没有大人脸也走真 200M 读出，仍然需要 1.0×、光线充足、非 HDR。

### XPAN

- **XPAN 显影水印**：XPAN 照片存为实况照片，播放时是负片显影动画，带原厂 XPAN 快门声。
- **XPan 取景净化**：小取景框遮罩、大取景框遮罩、显影动画三项分别开关。
- **XPAN 水印隔离**：XPAN 水印只在 XPAN 模式出现。

### 理光 GR 与移植模式

- **理光 GR 模式**（移植自 realme GT8）：影调、焦距条、快照对焦、相机和相册水印。
- **GR 快门声**：快门声和长曝光提示音。
- **GR 水印**：可以单独关闭，关掉后一直保持关闭。
- **GR 模式排序**：长按拖动，调整在模式栏里的位置。
- **POP 复古模式**（移植自 Reno16）：可在 SDR 和 Ultra HDR 风格之间切换；光线充足时可输出中像素，画面里有人脸时保持原尺寸。
- **X10 系列**：调色盘和清透、琥珀两款滤镜。
- **移轴模式**。

### 视频

- **4K / 60fps 视频滤镜**：普通视频在 4K、60fps 下保留滤镜，不会退回 1080p30。
- **专业视频 ISZ**：解禁传感器内变焦（主摄 2×、长焦 6×，O-Log2 也能用）。

### 相册

- **调色盘与滤镜重新编辑**：Muse 滤镜和大师滤镜进入相册的滤镜列表；按照片的拍摄方式进入调色盘编辑或滤镜编辑。
- **理光 GR 水印编辑**。
- **水印显示滤镜名**：Muse 滤镜和导入滤镜在成片、预设和相册重建的水印上显示自己的名字。
- **全系列水印**：哈苏、LUMO、理光水印对所有照片开放；截图这类没有机型信息的照片补上本机的厂商和机型名。
- **批量编辑水印**：多选照片后在"更多"里选，第一张选好样式，其余照片在后台自动套用，可以离开相册，实时通知显示进度；选"无"就是批量去掉水印。
- **地址跳转地图**：照片详情里点地址，在地图应用里打开拍摄位置。

### 快门声、快启键与机型

- **快门声**：静音和振动模式下也播放，可以分别开关；快门声音量可以单独设置。
- **按模式记忆**：闪光灯、实况照片的开关，每个模式各记各的。
- **快启键指定模式**：用快启键打开相机时直接进入指定模式，包括大师、GR 这些原厂快启列表里没有的，不跟随上次用的模式。
- **机型伪装**：水印上的机型名换成所选预设，也可以同时改成片 EXIF 里的机型；预设可以新增和管理。

### 主页与诊断

- **注入状态**：逐项检查 LSPosed、KSU 挂载、相机和相册注入、符号匹配，全部正常时卡片变绿。
- **重启相机、重启相册**。
- **日志**：可以持续记录系统日志，复现问题后一起导出，导出内容包括相机自己的日志。
- **设置即时生效**：改任何设置后，后台自动结束相机进程，回到相机就是新设置。

## 安装

需要已 root（KernelSU）并装好 LSPosed。

1. 构建出 `OmniCam-Muse-<版本>-KSU.zip`（见"构建"）。
2. 在 KernelSU 管理器里刷入模块（ID `ricoh_pop_x9u`）后重启。模块包里自带设置应用（包名 `local.jiege.camera`），刷入时一起安装。
3. 在 LSPosed 里启用 OmniCam Muse，作用域勾选**系统框架、相机、相册**。
4. 强制停止相机后重新打开。

设置在桌面的 OmniCam Muse 应用里，或者从 LSPosed 打开。回退：在 KernelSU 管理器里停用模块并重启，所有挂载都会还原。

## 其他机型

欢迎参考本项目给其他机型做适配。不过很多功能改的是底层配置：`/odm` 下的相机配置、调色与 LUT 资源、HAL 决策节点和原生库，这些都和机型、相机版本绑定，不能照搬到别的机型上。适配前请先看 `docs/MODULE.md` 里各功能的原理和涉及文件，再对照目标机型自己的配置逐项核对。

## 构建

环境：Windows、JDK 17、Android SDK 37、NDK 29.0.14206865、CMake 3.22.1、Python（含 numpy、pycryptodome）、Git for Windows。`local.properties` 里写 `sdk.dir=…`（已忽略）。

```powershell
$env:OMNICAM_PYTHON = 'python'
.\build.ps1
```

`build.ps1` 先跑色彩目录检查、离线测试和脚本语法检查，再执行 `assembleRelease`。

根目录有 `port.keystore`（已忽略）或设置了 `OMNICAM_KEYSTORE` 时，用 `OMNICAM_STORE_PASSWORD`、`OMNICAM_KEY_ALIAS`、`OMNICAM_KEY_PASSWORD` 签名，产出签名 APK 并打包 `OmniCam-Muse-<版本>-KSU.zip`；否则只产出未签名 APK。

证书和密码不入库。不同证书签名的 APK 不能直接覆盖安装。

## 目录

| 路径 | 内容 |
|---|---|
| `app/` | 设置应用与钩子：Java（`hook/*`）、Kotlin（`ui/*`）、C++（`cpp/*`，大师色彩引擎 `master_*`、柔光 `soft_light*`） |
| `module/` | KSU 模块：脚本、`payload/` 配置与资源、`system/odm/lib64/` 库 |
| `tools/` | 资源生成与离线测试：`mastercolor/`（大师色彩）、`softlight/`（柔光权重表）、`symbols/`（混淆符号特征）、`offline_tests/` |
| `tools/refs.py` | 仓库外参考资料的位置（`MUSE_REFS` 可改根目录） |
| `docs/` | `MODULE.md` 各功能的原理与涉及文件，`DEV_NOTES.md` 设备操作与排查 |
